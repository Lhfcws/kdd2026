### 观察

- **测评是绝对主线**：41/47 篇带「测评」标签，说明这批 KDD 2026 笔记高度集中于"如何评测 agent"——且大量工作把安全、可追溯性、自改进都纳入评测框架（如 trace-backed 评估、rubric verifier、judge 选择）。
- **安全隐私（13）与追溯性（12）并列第二梯队**：反映"可信 agent（trustworthy）"是两大量级话题。二者侧重不同——安全偏风险/攻击面与护栏，追溯性偏过程证据、生命周期与可复现。
- **记忆与检索最少（4），且全部与测评共现**：RAG / 长期记忆在这批论文里更多是"被评估的对象"（#16/#32/#37/#42），而非独立方法主线。
- **智能增强（8）与 Agent runtime（8）**：前者偏方法（自改进、规则学习、跨层对比学习），后者偏系统（编排、harness、脚手架效应）；二者有少量交叉（#43 同时命中智能增强+Runtime+安全隐私）。
- **「其他」为 0 篇，已从分布表移除**：47 篇均能归入前 6 类，说明这批 KDD 2026 录用工作整体集中在 agent 的"评测 / 可信 / 系统"方法论，领域应用型论文也多带有清晰的方法学角度。
