# Quantum Circuit Vision: Cost-Aware Evaluation of Visual AI Agents for Quantum Code Generation

## 背景与 Idea
量子算法多以电路图形式在论文、教材中传播，却需手动翻译成 Amazon Braket、Qiskit 等 SDK 的可执行代码——这一步繁琐且易错，是量子软件工具链的核心瓶颈。论文提出 Quantum Circuit Vision (QCV)，把"从量子电路图视觉理解并生成经过验证的可执行代码"作为 AI-for-Science 的基础挑战。其 idea 是构建首个多模态、成本感知（cost-aware）的量子电路视觉评测框架：不仅评估准确率，还联合评估延迟、单次调用成本与路由策略，并以单位矩阵保真度（unitary fidelity）作为不依赖 LLM 评判的客观 oracle，回答"视觉 agent 能否读懂量子电路图并生成可验证代码、成本几何"这一核心问题。

## 核心方法
QCV-Dataset 含 132 个电路、13 个类别（1–10 量子比特），每个电路配 5 种核心模态（PNG 图、Braket 代码、Qiskit 代码、仿真结果、双语标注），外加失败案例与目标描述。评估用两个视觉提示模式：Basic Vision (BV) 直接生成代码，Thinking Vision (TV) 先做链式思考再生成。验证走三级流水线：语法检查 (compile) → 执行检查（沙箱生成合法 Braket Circuit 且无运行时异常）→ 单位矩阵保真度检查（在 Braket LocalSimulator 上跑全部 2^n 计算基态，算 F=|Tr(U_gt†U_gen)|/2n，F≥0.99 判通过），该 oracle 对全局相位不敏感、比单输入态矢量比较更严格。实验固定 Claude 家族三档（Haiku 4.5 / Sonnet 4.6 / Opus 4.6），经 kiro-cli 统一非交互调用，共 132×3×2=792 次调用；核心 21 电路子集做 n=5 重复试验并用配对 t 检验与 TOST 等价检验，全 132 电路为 n=1 指示性结果。成本分析记录每次调用的平台积分、延迟、保真度，并提出 Haiku→Sonnet→Opus 的级联路由策略。

## Performance 概括
核心子集（n=5，BV）上 Sonnet 4.6 最准且最稳（91.4%±5.2%），Opus 4.6 次之（85.7%±5.8%），Haiku 仅 48.6%±4.0%；Sonnet–Opus 的 +5.7pp 差异不显著（配对 t p=0.083），而 Sonnet 单次成本仅为 Opus 的 18%（1.30 vs 2.20 cr/call）。全 132 电路（n=1）总体通过率 Opus 78%、Sonnet 77%、Haiku 43%，基础电路多数模型 80–100%，复杂算法/密码协议降到 41–87%，18 个电路所有模型均失败（Shor、表面码、BTC 安全协议等结构不规则者）。链式思考 (TV) 对任意模型均无统计显著效果（all p>0.18，n=5）；逻辑回归确认电路深度（p<0.001）而非量子比特数（p=0.20）是理解难度主预测因子。成本上 Haiku→Sonnet 边际成本 0.002 cr/pp（极划算），Sonnet→Opus 达 0.508 cr/pp（254× 边际）；级联路由以 30.9 积分（Opus 单独成本的 38%）取得 84% 通过率。与人工翻译（估 $50–200/电路）相比，最贵模型约 $0.78/电路，降本 >100×。

## 论文价值与不足
价值在于首次把"多模态视觉→可验证量子代码"做成带客观 oracle、成本感知、统计严谨（n=5 重复+配对检验+TOST）的完整评测基础设施，并发布含 FAIR/CARE 治理元数据、Datasheets、Croissant-RAI 的开放数据集（Hugging Face 上 132 电路、1,931 文件），其"结构复杂度而非量子比特数决定成败""CoT 无效""模型路由胜过提示工程"等发现对科学图理解的 agent 评测具普适启发。不足在于：仅测 Claude 家族三档（固定厂商以隔离能力-成本档效应），未覆盖 GPT-4o/Gemini 等跨厂商；电路图均由 Qiskit matplotlib 渲染，未测 TikZ/Quirk/手绘等真实异质渲染；端到端验证仅经 Braket 包装，跨 SDK（Qiskit Aer/Cirq）实证验证为未来工作；全 132 电路与成本/级联结论为 n=1，统计显著声明仅限于核心子集；仅处 Level 1（理解+代码生成），优化与发明层未实证。

## 工业界落地可行性评估
该框架对量子计算研发辅助、量子密码/区块链安全、科学图理解的 agent 部署有明确落地场景：其级联路由（廉价→昂贵模型）与边际收益分析可直接用于成本敏感的批量电路翻译任务，人工+AI 混合流程把单电路成本从约 $100 降到 $23，使大规模电路翻译首次具备经济可行性；单位保真度 oracle 提供的客观验收标准也适合嵌入 CI/CD 做自动验证。但当前限于单厂商、单渲染器与 n=1 全量结论，工业落地前需扩展跨厂商模型、真实电路图样式与跨 SDK 验证，并优先在"人工校验兜底"的人机协同工作流中试点，而非完全自动化可信发布。
