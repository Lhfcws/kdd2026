# Clustering-based Prompt Optimization for LLM Evaluation

## 背景与 Idea
LLM 作为评估器（"AI 裁判"）越来越多地替代人工评分搜索质量等任务，但其与人工的共识高度依赖评分 rubric（评分细则）的措辞——论文实验中仅给手写 baseline 加一条规则就使某任务的留出集共识提升 +41.67 分。问题在于：专家标签稀缺（数百条双评查询）、每次评估调用本身是昂贵的 LLM 推理，因此通用 prompt 优化器（DSPy/MIPRO、GEPA）假设"评估廉价且充足"的前提被打破。作者将问题重新定义为"数据效率问题"：在固定的训练查询与专家标签预算下，如何用最少的评估调用最大化留出集上的人—AI 共识，提出了"cluster + batch-validate"单次循环作为解法。

## 核心方法
论文对比三种方法在来自同一商业搜索垂类（非英语市场、300 条双评查询）的两个评估任务上：直觉式 linear loop（读最差分歧→改→重评，循环）、自动化优化器 GEPA（10–20 轮反思式变异+帕累托前沿）、以及提出的 cluster loop。cluster loop 仅跑一次端到端：① 收集 v0 baseline 在训练集上的所有分歧；② 用 4–5 路并行 proposer 调用（多输入洗牌+多提示重构）做语义聚类；③ 按跨运行共现（(N-1)/N 次同簇）过滤出稳定共识失败族；④ 每族生成一个原子级单条规则变体、锚定到正确 rubric 步骤并加一行跨步作用域护栏；⑤ 并行批量校验（每变体 ~5 分钟），计算 composite Δ、跨维 bleed 与 200 次自助采样的 Δ 分布；⑥ 仅当通过 Table 2 四道预注册门（train 增益、bootstrap P(Δ>0)≥95%、跨步护栏、canary 回归）才接受；⑦ 只对胜出变体做单次留出测试。评估指标为 composite = exact% − 0.5×MAE×100（序数 0/1/2，越高越好）。

## Performance 概括
在留出集单次测试中，cluster loop 是两个任务上唯一稳健为正的方法（P(Δ>0)=100%）：Vertical Candidate 上 C1 达 +6.00（v0 40.33→46.33，95% CI [+3.0,+11.5]），而 linear 仅 +0.67（P=55%）、GEPA +1.67（P=79%）；Vertical Quality 上 F3 达 +41.67（v0 33.33→75.00，CI [+16.7,+70.0]），远超 linear 的 +9.52 与 GEPA 的 +16.67。验证阶段显示单种子验证会严重误导（linear 被夸到 +10.00 的采样假象），而 8 折多种子均值排序与留出集一致：C1 多种子 +7.75±4.53、linear +1.25±3.06。成本上，一次 cluster loop 约 US$25，与 linear 全量运行相当、远低于 GEPA 的 10–20 轮，且产出更强 rubric。需注意 Vertical Quality 的有效留出配对仅 36–42 对（因 S4 可评性过滤），点估计不精确，增益集中在修复 baseline 单一"vertical card 识别"定义缺陷上。

## 论文价值与不足
价值在于提出并实证了一条可落地的"配方"：一次性聚合所有分歧→每失败族发布一条具名规则→仅在噪声感知多种子自助检验下接受编辑；相比迭代式搜索，其杠杆是"一次性聚合完整错误集 + 噪声感知选择"而非迭代深度，且每条原子规则可独立审计、回滚，对"标签预算吃紧下需让 LLM 裁判跟踪人工判断"的场景普遍适用。不足：仅两个同垂类、同评估器（Codex/gpt-5.4）、重叠双分析师池的任务，外部有效性未验证；协议上同时改动三个轴（全池聚合/原子编辑/多种子选择）未做成分消融；聚类只用单一 proposer；gate 不检查同一维度上与 baseline 文本的矛盾；Vertical Quality 有效样本极小、增益高度集中于单一缺陷，典型增益幅度可能更接近 Candidate 的 +6.00。

## 工业界落地可行性评估
落地可行性高，且直接面向生产环境（已在某商业搜索引擎垂类的真实质量审计批次上验证）。该 loop 以"人—AI 共识"为目标、以稀缺专家标签与推理预算为约束，单元是版本化、带 changelog 的具名规则，gate 自动决定接受、人工事后审计，回滚按规则粒度进行，契合工业界搭建 human-aligned LLM 评估器的实际工作流。可迁移到任何"LLM 裁判须在小标签预算下跟踪人工判断"的场景，论文亦指出可移植到 agent trace/工具调用轨迹打分（把分歧聚类到轨迹步骤、原子规则锚定到决策点）。落地前提是需要两名以上独立标注者提供分歧信号、且评估器本身需足够强（近地板模型无信号可搜）。
