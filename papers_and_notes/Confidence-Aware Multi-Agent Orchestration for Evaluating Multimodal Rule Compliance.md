# Confidence-Aware Multi-Agent Orchestration for Evaluating Multimodal Rule Compliance

## 背景与 Idea
多模态规则合规评估（例如判断图文内容是否违背平台规则）需要综合视觉与文本两类证据，而单一模型在跨模态信息相互冲突时容易出错。针对这一痛点，作者提出了置信度感知的多智能体编排框架：让多个专家 agent 协作完成评估，并显式引入各 agent 的置信度来协调分歧、融合判断。其出发点是在"感知—判定"两段式流程中，用置信度作为调度信号来抑制单模型在模态冲突下的误判。

## 核心方法
框架采用 perception-then-judgment（先感知、后判定）流程：多个多模态 agent 先各自独立提取证据，再由编排层基于各 agent 输出的置信度执行跨模态冲突解决（cross-modal conflict resolution）并给出最终判定。评估在 38 条规则上进行，并以 216 条经过人工验证的样本作为真值来检验效果。该方法强调轻量与可解释，把置信度显式建模进多 agent 的编排与融合环节。

## Performance 概括
在 216 条人工验证样本上，框架整体准确率达 89.8%、F1 为 92.5%，相比最强基线提升约 12.5pp（准确率）与 9.0pp（F1）。跨模态冲突解决机制相对无该机制的版本，F1 提升约 13.9%，说明置信度驱动的冲突协调确实带来实质增益。

## 论文价值与不足
价值在于把置信度显式建模进多 agent 编排，并以冲突解决机制缓解多模态误判，方法轻量且具备可解释性。不足是验证仅在 38 条规则与 216 条样本的小规模集合上完成，规则覆盖面与样本规模都有限，其泛化能力还需在更大规模、更丰富规则集上确认。

## 工业界落地可行性评估
较可行。该框架面向内容审核、合规检查等需要多模态证据融合的场景，可直接用作平台规则合规的自动化初筛环节。但在规模化部署前，需补充更大规模、更丰富规则集的验证，并评估在真实生产流量下的时延与成本。
