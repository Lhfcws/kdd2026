# When Consensus Is Not Correctness: Diversity Collapse and Manufactured Overconfidence in Multi-Agent LLM Debate

## 背景与 Idea
多智能体大模型辩论（multi-agent LLM debate）指让若干个模型实例在多轮交互中各自给出答案、阅读彼此论证并最终汇总，被广泛认为能提升答案质量。它常被嵌入 agentic 管线，且专家小组的"表面置信度"直接决定下游动作：是作答、弃权还是升级。一个渗透很广的直觉（源自人类审议与集成学习 ensemble learning）是：agent 之间的一致（consensus）意味着答案更可能正确，因此一致既可当作置信信号，也可当作停止准则（典型如 "debate until consensus"，即"辩论到一致就停"）。同一套"一致即置信"的逻辑远不止于辩论本身，它还支撑着自一致性解码（self-consistency，对同问题多次采样取多数）、多数投票（majority voting）、以及"用一个模型评判另一个模型"（LLM-as-judge）、自验证等做法。本文的核心主张是：在一个重要且可预测的 regime 下，这个直觉是反的——辩论确实会稳定地产生一致，但这种一致是辩论过程内生的（endogenous），由"正在被它认证的那次交互"自己制造出来，因此它不能作为校准过的正确性信号；把它当置信度读，反而会制造过度自信（overconfidence）。一句话原则：自己产生的共识无法认证它的生产者；共识只是"提出答案"的通道，不是"认证答案"的通道。

为什么危险？不是错误本身，而是附在错误上的置信度：一个被标为"不确定"的答案会触发人类二次审查，而一个"自信且一致的错误共识"会静悄悄地穿过本应拦截它的关卡。论文证明，在模型根本不确定的任务上，agent 依然会收敛到一个自信的错误共识——操作员最想信任的信号，恰好在最难的任务上最不可靠。这与近年一系列"给辩论降温"的发现一致：有研究指出辩论并不总优于单模型或自一致性，有研究记录同质 agent 在重复交互中趋近几乎相同的输出（语义坍塌），还有研究从信息论角度论证"输出多样性而非 agent 数量或轮数"才是维持增益的关键。本文的独特点是用经典集成方差理论把这些观察统一到一个可量化机制下。

值得强调的是，这种"一致即正确"的直觉之所以危险，是因为它常常是对的——在 agent 真正多样化、且任务留有纠错余量时，辩论确实能降低误差，此时一致是可用的弱信号。问题出在辩论的"内生性"：当 agent 互相读取彼此论证，它们的输出不再是独立样本，而是被同一条交互"污染"的相关样本，于是方差恒等式中的相关性 ρ 单调上升。此时一致性不再反映"多个独立意见趋同"，而只反映"大家被同化到了同一处"。操作员无法从外部转录区分这两种情况，因此最危险的是：在模型最不确定的难题上，一致反而最不可靠，却看起来最自信。

## 核心方法
机制被一个经典方差恒等式精确化。把每个 agent 第 t 轮的输出当作一个带噪声的正确性估计 X_i(t)，具有每 agent 方差 σ²(t) 与跨 agent 相关性 ρ(t)；团队聚合的方差满足 equicorrelation 恒等式 Var(μ̂_t) = σ²(t)·(1+(N−1)ρ(t))/N。关键在于：agent 互相读取彼此输出会使其"同化"（assimilate，即网络多智能体系统中长期研究的共识动态），于是 ρ(t) 趋向 1，这就是"多样性坍塌"（diversity collapse）。当 ρ(t)→1，括号项趋向 N、1/N 的平均收益消失，集成不再降低误差；与此同时，外部读者（或 agent 自己）用来判断确定性的"观测到的分歧"趋向 0。于是表观确定性上升、真实误差却不降——同一个 ρ(t) 把两个量推向相反方向。论文据此推出三个后果：面板表观置信度趋于饱和且与误差无关；校准缺口（confidence − accuracy）因此追踪残差误差，故辩论在模型最不准确的任务上制造最多过度自信；辩论是否良性取决于"纠错速度是否跑赢置信膨胀速度"，而这由角色设计（agent 是批判还是说服）与任务余量（headroom，还有没有错可纠）决定。定理 4.5 给出"产出型—过度自信型"二分：校准改善当且仅当准确性提升 ΔA 超过置信膨胀 ΔC≥0。推论 4.4 进一步指出，过度自信在不可约误差大的难/歧义任务上最大、在已饱和任务上几乎为零，与角色无关。

针对该结构性失败，论文提出 certification-first（认证优先）的修正框架 CMAD（Calibrated Multi-Agent Debate），按"对内生信号信任度递减"分三档，且只有最外生的一档与坍塌无关。第一档 Prevent（防止）：Verdict-Sequestered Debate（Sequester），在标准辩论中每个 agent 会看到同伴上一轮完整消息（含 "ANSWER: k; CONFIDENCE: c"），Sequester 只改一处——在把同伴消息发给他人前，把"承诺的答案/置信度行"用占位符替换，使 agent 仍能交换推理、却看不到彼此声明的答案与置信度；这是消息转发层的一行改动，零额外成本，针对驱动 ρ(t)→1 最显著的耦合通道（可见结论），但保留推理、修辞与角色诱导的顺从，故其效果是有条件、经验性的。第二档 Detect（检测）：Deliberation-Speed Trust（Deliberation），在终端信号因坍塌失效、但坍塌前轨迹仍幸存时，用一个逻辑回归头在七个"无标签轨迹特征"上打分（首尾轮的自报置信度与答案一致度、模态答案改变的轮数、置信度变化、到达共识的耗时、一致度首次越过阈值的轮次），用于选择性预测——τ 高则提交、低则弃权或升级；它在其他条件上训练、可零标签迁移到未见域，且在置信度已失去排序信息处才起作用（消融显示去掉任一单特征 AUROC 变动 <0.004，印证推论 4.2）。第三档 Certify（认证）：Conformal Verdict Affirmation（Affirm），用 split-conformal 把提交答案包装成分布无关的覆盖保证——以概率 ≥ 1−α 保证真实标签落在返回集合内，而非保证某个单答案正确；它不读取任何内部信号，故能腐蚀所有一致性启发式的坍塌无法使其覆盖失效。定理 5.4 证明在标定集与测试集可交换时边际覆盖成立、与 ρ(t) 无关；定理 5.5 证明其"认证停止"规则在独立选择折上选停止轮、在独立阈值折上算阈值，仍保持边际覆盖，无需 Bonferroni 惩罚。命题 C.1 说明叠加 Prevent/Detect 只改效率、不改覆盖。

三档设计体现的是一种"信任降级"的务实哲学：先用最便宜的 Prevent 在协议层削弱内生性，若仍无法阻止坍塌则用 Detect 在坍塌前的轨迹里捞回一点判别力，最终用与坍塌无关的 Certify 兜底。这种分层使得工程上可以渐进采用——不必一步到位实现 conformal，也能先获得部分收益。对理论读者而言，最关键的是定理 4.5 给出的二分：辩论是否改善校准，完全取决于"纠错速度 ΔA 是否超过置信膨胀速度 ΔC"，而 ΔC 在坍塌下恒为正，所以符号由 ΔA（角色设计与任务余量的性质）决定，这把"辩论好不好"从一个模糊直觉变成了可分析的因果关系。

## Performance 概括
在 15 个任务的受控研究中，跨 agent 相关 ρ̄ 从首轮 0.53 升至末轮 0.96（30/30 个条件都成立）；末轮一致度 κ̄(T)=0.997，置信被压缩到 [0.90,1.0]（均值 0.96），而准确率却跨度 [0.57,0.99]。过度自信 gap 与残差呈仿射关系，斜率 0.82、R²=0.96；准确率变化与 ECE 变化的相关系数 r=−0.46。单看一致性的 AUROC 仅 0.49–0.58（几乎无法检测错误），而基于一致性的停止规则误覆盖高达 18–47%。实验模型为 GPT-4o-mini 与 QwQ-plus，基准含 CommonsenseQA 与 GSM8K，并在五个模型家族上复现、扩展到自由生成，结论一致。

## 论文价值与不足
价值在于用"经典方差理论 + 实证"清晰揭示 debate 一致性的"过度自信制造"机制，并给出可证明覆盖（split-conformal）的 Certify 解法与可操作的 Prevent/Detect 前置档，立场鲜明、理论扎实。其"内生信号无法用更好的校准修复、必须来自该循环之外的量"的判断，对一切把一致/自洽当作置信的做法都有警示意义——它不仅批评辩论，也间接质疑自一致性、多数投票、"辩论到一致即停"等广泛使用的工程习惯。论文还给出可证伪的清晰预测（终端缺口随残差单调变化、局部斜率在 (0,1]），使理论可被实证反驳。

不足有三：一是实验主要限于 QA 与自由生成类基准，对工具调用、更开放场景的验证还需补充，且角色设计只覆盖 cooperative 与部分 adversarial 设定；二是 Certify 返回的是集合而非单答案，集合可能偏大而影响可用性（需在覆盖与集合大小间权衡），对必须输出单一答案的下游需额外呈现策略；三是 Prevent/Detect 两档依赖模型与条件，并非坍塌无关，其收益有 regime 限制（如 Sequester 仅在 cooperative 设定上观察到有限效果），只有 Certify 是无条件保证。此外， conformal 的覆盖保证依赖标定集与测试集"可交换"这一前提，在分布漂移或对抗性输入下需重新标定。

## 工业界落地可行性评估
落地性明确且收益高、风险低。任何用多 agent 辩论或自一致性（self-consistency）/多数投票来估计置信、决定"是否停止/是否作答"的场景，都应改用 conformal 的 Certify（Affirm）而非"一致即停"——尤其在高风险决策（医疗、金融、运维）中，虚假一致带来的过度自信代价极高，而 Affirm 以分布无关的覆盖保证直接替代之。对工程更友好的是：Prevent（隐藏同伴答案行）是消息层一行改动、零成本，可在不换模型的前提下先降低坍塌；Detect 可在无标签情况下做选择性预测与升级，把"到达共识的耗时"等轨迹特征当成是否可信的信号。

落地障碍主要是 conformal 需要一批可交换的标定数据来定分位数阈值，且集合答案需配套"给出多个候选而非单一答案"的下游呈现；在延迟极敏感、必须单答案的场景，Certify 的集合大小开销需结合业务容忍度调 α（例如放宽到 90% 覆盖以缩小集合）。另一现实考量是多数现有多 agent 框架把"一致"直接当停止条件，改造为 CMAD 需接入轨迹特征提取与独立标定/阈值折，工程量中等但收益明确。总体而言，这是一次低风险、高收益的工程替换，可直接嵌入现有多 agent 系统的停止/门控逻辑，且不与具体模型绑定。

需要提醒的是，conformal 的覆盖保证依赖"标定集与测试集可交换"这一统计前提，在分布漂移、对抗性输入或评测集与训练集高度同源时，覆盖可能失效，因此标定集应来自与部署流量同分布的数据并定期刷新。另一现实考量是，多数现有多 agent 框架把"一致"直接当停止条件，改造为 CMAD 需接入轨迹特征提取与独立标定/阈值折，工程量中等但收益明确；对只需单答案的下游，可用"集合内取置信最高者"作为默认呈现、同时保留集合以备升级。鉴于论文在五个模型家族与自由生成上均复现一致，外推风险较低。
